# How this guide stays current

## Where the club’s information lives

GitHub is the public-facing version of the club information. The founders’ shared Google Doc is our internal working record for suggestions, notes, decisions, and revision history. Accepted changes are incorporated there, and information relevant to visitors is reflected here on GitHub. A spreadsheet or public suggestion feature may be considered later.

Update this guide from submitted notes and minutes. Preserve decisions and recaps, distinguish proposals from confirmed plans, and log revisions. Record agreed task owners and dates in the shared working record; return the revised guide with each update.

## Version control with Git

The Guide’s text lives in a Git repository on GitHub. Every change is saved with who made it, when and why, and any two versions can be compared. A suggested edit becomes a pull request that the other founders review and accept, so the history doubles as the edit log. Small lists (books, actions, meeting dates) can live in the repository as tables; tasks fit GitHub Issues. For now, suggestions and reviews stay in the shared Google Doc. GitHub pull requests and Issues remain options for later.

## A site anyone can use

The published Guide (GitHub Pages) is set up so anyone can find their way around it: a home page that says what the club is and when it meets, a short menu (About · How meetings work · Books · Join us · Recaps), plain-language page titles, and pages that read well on a phone. No account or GitHub knowledge is needed to read it. Reading is open to all; only editing goes through review.
